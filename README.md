# 🚀 FormAI

An AI-powered form builder that generates dynamic forms from natural language prompts, collects responses, and provides insightful statistical analysis.

Built using **React**, **TypeScript**, **Hono**, and **Cloudflare Workers**, FormAI enables users to create, manage, share, and analyze forms with the help of Google's Gemini AI.

---

## ✨ Features

* 🤖 AI-powered form generation using Google Gemini
* 📝 Create intelligent forms from simple prompts
* 📤 Share forms through public links
* 📊 Real-time response analytics and visualization
* 📁 Manage all created forms in one dashboard
* 💾 Securely store responses
* 📈 Statistical analysis using interactive charts
* ⚡ Fast edge-powered backend with Cloudflare Workers
* 🎨 Modern and responsive user interface

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/adrika-mandal-tech/FormAI.git
cd FormAI
```

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file using the provided `.env.example`.

### Run the development server

```bash
npm run dev
```
